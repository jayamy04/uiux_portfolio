Website Redesign Card Sorting

Goal

Understand how riders naturally group and label transit information when using the Sound Transit website. The findings will inform improvements to information architecture, navigation clarity, and discoverability of key tasks. If users clearly bucket business/ community/ rider content

Participants: 50

Card Sorting Instructions

Now you will be presented with a set of Cards that you will need to associate with the "Category" you think best matches the word/phrase.

There are no right or wrong answers — we are interested in how you naturally organize information.
